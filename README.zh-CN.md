# TailBuddy

[English](README.md)

**通过其他 Tailscale 设备访问 Mac 上的服务，同时保留你现有的上网和代理设置。**

TailBuddy 常驻 macOS 菜单栏，让这台 Mac 在你的 Tailscale 私有网络中拥有独立身份。离开电脑时，也可以访问本机的开发网站、管理面板或其他服务。

## 能做什么

- **远程访问本机服务。** 使用 TailBuddy 的 Tailscale 地址和服务原有端口，无需逐个配置端口。
- **保留现有代理设置。** 适合希望继续使用代理软件、同时远程访问 Mac 服务的场景，不接管 Mac 的日常上网。具体兼容性取决于代理软件的设置。
- **后台菜单栏常驻。** 随时查看状态、连接、断开或打开设置。
- **可选共享子网。** 允许其他设备访问这台 Mac 能连接的指定网络，默认关闭。
- **英文和简体中文。** 跟随 macOS 的语言、单应用语言和深浅色设置。

## 安装

支持 macOS 12 及以上，提供 Apple silicon 和 Intel 两种版本。

1. 打开[下载页面](https://github.com/ImSingee/TailBuddy/actions/workflows/ci.yml)，选择最近一次成功的运行。在 Artifacts 中下载 `TailBuddy-macos-arm64`（Apple silicon）或 `TailBuddy-macos-amd64`（Intel）。下载需要登录 GitHub。
2. 解压下载文件，再解压其中的应用 zip。
3. 将 `TailBuddy.app` 移入「应用程序」并打开。

应用尚未经过 Apple 公证，macOS 可能阻止打开。

## 开始使用

1. 阅读访问提示，确认入站访问和保存登录信息的授权。
2. 点击「连接」，再点击「登录 Tailscale」，登录你要使用的网络。
3. 在同一网络中获准访问的另一台设备上，使用 TailBuddy 显示的地址和服务原有端口。例如，本机网站使用端口 3000，就访问 `http://<TailBuddy 地址>:3000`。

关闭窗口后，TailBuddy 仍在后台运行。「断开连接」或「退出」会停止访问，但保留登录信息。打开应用或登录 Mac 时启动应用，都不会自动连接。

### 可选子网访问

在「访问设置」中开启「通告子网」，填写要共享的网段，确认访问提示后保存。关闭该选项并保存，即可停止共享这些子网。

路由可能需要 Tailscale 管理员批准；已配置自动审批的网络可能立即生效。访问规则和连接方设备的设置也必须允许。保存成功不代表已经能够访问。

### 选择语言

默认跟随 Mac 的语言。也可以在「系统设置 → 通用 → 语言与地区 → 应用程序 → TailBuddy」中单独选择语言，然后重新打开应用。

## 连接前请留意

- 所有支持的本机端口，包括连接期间新启动的服务，都可能被 Tailscale 规则允许的设备访问。请为私有面板和管理工具启用身份验证。
- 部分服务会把传入连接视为本地访问，不要只依赖“仅限 localhost”来保护它们。
- 本机服务访问支持可通过 `127.0.0.1` 连接的 TCP/UDP 服务，部分 Tailscale 保留端口除外。仅监听其他地址的服务可能无法使用。
- 仅共享你确实希望开放的子网。代理或 VPN 设置可能影响连接。
